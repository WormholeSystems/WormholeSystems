# Getting help

Stuck, found a bug, or want to suggest something?

## GitHub issues

For reproducible **bugs** and concrete **feature requests**, open an issue on the
[repository](https://github.com/wormholesystems/wormholesystems). A clear issue is
easier to track and fix than a message that scrolls away in chat, and it is where the work
actually gets picked up.

Worth saying what you expected and what happened instead. For anything to do with the map,
which systems and connections were involved usually decides how quickly it can be
reproduced.

## This documentation

A lot of "how does X work" is answered here. Use the sidebar to browse, and remember that
most things on the map are
[right-clickable](/documentation/getting-started/right-click-menus) — the menu is usually
where the answer is.

## A word on the state of it

This is pre-alpha. Some things are missing, some are half-built, and some worked last week
and do not today. If something looks broken it might genuinely be broken, and saying so is
useful.
